# SKILL 私家抖音 

> 用你的私家收藏作为内容库，StepFun 3.7 Flash 作为推荐引擎，为你的碎片时间，打造你的私家抖音

private-douyin 聚合你的数字囤货 —— 本地浏览器书签、本地备忘录、本地 NAS 收藏、Bilibili 收藏夹、小红书收藏夹   

在你想看点什么时，由 StepFun 3.7 Flash 从你的囤货里选一条做成 feed 发到你的飞书

## 核心特性

### 🎯 情感化推荐
LLM 会结合聊天历史、当前时间、用户情绪，从候选池中挑出最能**产生共鸣**的一条，并生成有共情、有画面、有温度的推荐语。

### 🔄 多源聚合，慢慢清空收藏夹
- **Safari 书签**：你收藏的宝藏链接
- **macOS 备忘录**：你的生活清单与灵感碎片
- **Bilibili 收藏**：你的私家 b 站收藏
- **小红书收藏**：你的私家小红书收藏

### ⏱️ 智能时长适配
支持自然语言时长筛选：
- `s` / `开刷`：默认 3 分钟以内的轻量内容
- `s 5` / `s 5分钟`：约 5 分钟
- `s 半小时` / `s 1小时`：中长内容

### ❤️ 用户反馈闭环
飞书卡片自带 **「喜欢，下一条」** 和 **「不喜欢，下一条」** 按钮：
- 点击后自动记录到本地偏好文件
- **已推荐过**或**点过「不喜欢」**的内容，下次自动排除
- 你的每一次点击，都在优化未来的推荐

### 🚫 智能去重
基于 `item_id` 的去重机制，确保：
- 同一内容不会被重复推荐
- 你不喜欢的内容永远不再出现
- 推荐历史持久化存储，跨会话生效


## 工作原理

```
用户输入触发词（如"开刷"、"找点乐子"）
        ↓
LLM 感知用户当前状态（情绪、时间、聊天历史）
        ↓
脚本聚合多源数据 → 时长筛选 → 去重过滤
        ↓
LLM 深度分析候选内容，生成温情推荐语
        ↓
脚本发送精美飞书卡片（含反馈按钮）
        ↓
用户点击按钮
        ↓
本地回调服务记录偏好
```


## 快速开始

### 触发关键词

用户可以在飞书中对「私家收藏 Bot」发送以下任意关键词触发推荐：

- `s` / `t` / `推` / `recommend`
- `开刷` / `刷一刷` / `逛逛` / `找点乐子` / `碎片时间`


## 技术特点

### 1. 无侵入式数据采集
所有数据源均使用**无权限弹窗**的公开接口或本地文件读取，不会弹出钥匙串、登录等系统弹窗，保证自动化流程的流畅性。

### 2. 本地优先的隐私设计
- 用户偏好存储在本地 `~/.private-douyin/preferences.json`
- 回调服务运行在 `127.0.0.1:18789`，不暴露到公网
- 推荐历史、喜欢/不喜欢记录完全由用户掌控

### 3. 优雅降级
- 如果本地 18789 端口被占用，回调服务自动跳过，不影响卡片发送
- 如果某个数据源不可用，自动 fallback 到其他源
