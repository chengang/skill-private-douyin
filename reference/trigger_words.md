# 触发词配置

> 本文件集中管理所有触发词。添加新触发词只需在此处修改，无需改动脚本逻辑。

## 当前触发词

| 触发词 | 说明 | 场景 |
|--------|------|------|
| `s` | 默认命令 | 最简短的触发方式 |
| `t` | 默认命令 | 与 `s` 等价 |
| `推` | 中文动词 | 用户说"推荐点东西"时 |
| `recommend` | 英文 | 习惯用英文的用户 |
| `推一推` | 中文口语 | 更随意的表达 |
| `开刷` | 最口语化 | "我要开始刷了" |
| `刷一刷` | 轻松随意 | "随便刷点什么" |
| `逛逛` | 场景化 | "去逛逛内容" |
| `找点乐子` | 明确需求 | "给我找点乐子" |
| `碎片时间` | 场景化 | "我有碎片时间，推荐点东西" |

## 添加新触发词

在 `scripts/spark.py` 的 `argparse` 中，给 `command` 参数的 `choices` 列表添加新词。

```python
parser.add_argument(
    "command",
    nargs="?",
    default="s",
    choices=["s", "t", "推", "recommend", "开刷", ...],
    help="命令: s/t/推/recommend/...=收集数据",
)
```

同时在本文件中记录新词及其场景说明。

## 触发词分类

### 极简型
- `s`、`t`
- 特点：单字母，最快输入

### 中文动词型
- `推`、`推一推`
- 特点：直接表达"推荐"意图

### 口语场景型
- `开刷`、`刷一刷`、`逛逛`
- 特点：模拟真实聊天场景

### 需求明确型
- `找点乐子`、`碎片时间`
- 特点：用户直接说出需求场景

## 设计原则

- 触发词必须**足够短**，减少输入成本
- 触发词必须**足够口语化**，像真实聊天
- 避免与常见词汇冲突（如 `ls`、`cd` 等 shell 命令）
- 每个触发词应有明确的**使用场景说明**
