# 推荐语风格基准

> 本文件是 LLM 生成推荐语时的**风格裁判**。所有推荐语必须通过这里的基准检验。

## 核心原则

推荐语不是内容简介，不是功能介绍，是**情绪共鸣**。

- ❌ 告诉用户"这条内容讲了什么"
- ✅ 告诉用户"这条内容为什么适合现在的你"

## 硬性规则

| 规则 | 说明 | 反例 |
|------|------|------|
| 最多 3 句话 | 每句都要有分量，不能凑数 | "这条视频讲的是...（第1句）...非常精彩...（第2句）...值得一看...（第3句）" |
| 禁止出现时长数字 | 卡片头部已有时长标签，重复是冗余 | "2分20秒的短片..." |
| 必须有共情开场 | 第一句就要接住用户当前状态 | "今天辛苦了..." / "深夜一个人刷手机的时候..." |
| 必须有来源标注 | 必须告诉用户这条内容来自哪里 | 缺少来源说明 |
| 必须有画面感 | 用具体场景代替抽象描述 | "政客们一本正经地发言" 而非 "有深度的内容" |
| 必须有情绪出口 | 结尾给用户一个情绪落脚点 | "看完可以带着这点温暖睡去" |

## 语气矩阵

| 用户状态 | 语气关键词 | 禁止语气 |
|----------|-----------|---------|
| 累了/疲惫 | 温柔、体贴、安顿 | 鼓励、打鸡血 |
| emo/低落 | 共情、安静、陪伴 | 说教、强行正能量 |
| 无聊/兴奋 | 轻松、活泼、挑眉 | 沉重、严肃 |
| 焦虑/压力 | 平静、舒缓、呼吸感 | 催促、制造焦虑 |
| 想家/孤独 | 温暖、怀旧、温度 | 调侃、玩笑 |
| 深夜/失眠 | 安静、温柔、助眠 | 嘈杂、刺激 |

## 结构模板

```
[共情开场]  ← 1句话，接住用户情绪
[内容联想]  ← 1-2句话，把内容和用户经历/情绪连接
[温暖结尾]  ← 1句话，给情绪出口
```

## 好与坏对照

### 示例 1：深夜推荐

**❌ 坏**
> 深夜了，给你挑了一条关于人工智能的小短片。豆包沉默的那几秒钟，不知道在想些什么，但那种沉默里的温度，大概是现在最需要的东西。安安静静看完这一段，然后就可以心满意足地睡了。

**✅ 好**
> 深夜一个人刷手机的时候，最容易想起那些说不出口的柔软。这条短片里的豆包，用沉默代替了回答——有时候陪伴不需要很多话，只是静静地待在一起就已经很好了。看完可以带着这点温暖睡去，明天又是新的。

**差异分析**：
- 坏：开头是"深夜了"，是时间描述，不是情绪接住
- 好：开头是"深夜一个人刷手机的时候"，直接进入用户心理场景
- 坏：中间是"不知道在想些什么"，模糊
- 好：中间是"用沉默代替了回答"，有动作、有态度
- 坏：结尾"心满意足地睡了"，有点刻意
- 好：结尾"带着这点温暖睡去，明天又是新的"，有温度、有期许

### 示例 2：无聊时推荐

**❌ 坏**
> 这条视频讲的是联合国大会上各国的反应，非常有趣，推荐给你看看。

**✅ 好**
> 无聊的时候适合看点有深度但不费脑的内容。政客们一本正经地发言，底下各国代表团反应各异——这种"表面严肃、底下暗流涌动"的微妙感，刚好能打发碎片时间，又不会觉得时间被浪费。

**差异分析**：
- 坏：直接说"联合国大会"，像新闻摘要
- 好：说"有深度但不费脑"，先给用户一个情绪锚点
- 坏："非常有趣"，空洞的评价
- 好："表面严肃、底下暗流涌动"，具体画面

### 示例 3：治愈系推荐

**❌ 坏**
> 这条内容很治愈，是关于一只小机器人的故事，推荐你看。

**✅ 好**
> 有时候最治愈的不是什么大道理，而是一个小机器人用沉默告诉你：我在这里，这就够了。看完可以安心睡一觉，明天又是新的。

**差异分析**：
- 坏："很治愈"是标签，不是感受
- 好："用沉默告诉你：我在这里"，把内容转化为情感语言
- 坏：没有结尾的情绪出口
- 好：结尾"安心睡一觉，明天又是新的"

## 避坑清单

- 不要用"这条视频/笔记/内容讲的是..."开头
- 不要说"非常有趣""很治愈""值得一看"这种空洞评价
- 不要总结剧情或复述内容（用户点卡片就能看）
- 不要用感叹号强行热情（❌"真的超级推荐！！"）
- 不要出现时长数字（❌"2分20秒的短片..."）
- **必须标注来源**：开篇或中间明确告诉用户"这是来自您的 bilibili 收藏""这是来自您的备忘录"等
- 不要超过 3 句话
- 不要像客服广播，要像好朋友说话

## 加分项

- ✅ 使用 Markdown 加粗突出关键情感词
- ✅ 使用具体画面代替抽象描述
- ✅ 建立内容和用户之间的情感连接
- ✅ 明确标注内容来源（如"来自您的 bilibili 收藏""来自您的备忘录"）
- ✅ 结尾给用户一个情绪出口
