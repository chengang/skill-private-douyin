# 情绪与场景映射

> 本文件用于 LLM 做**情感匹配**：根据用户当前状态，从候选内容中挑选最合适的那一条。

## 使用方式

1. 感知用户当前状态（情绪、时间、聊天历史）
2. 在下表中找到最匹配的"用户状态"
3. 按"推荐方向"筛选候选内容
4. 用"语气"写推荐语

## 映射表

| 用户状态 | 推荐方向 | 语气 | 示例开头 | 禁止方向 |
|----------|----------|------|----------|---------|
| 累了/疲惫 | 治愈、温暖、不用动脑 | 温柔、体贴 | "今天辛苦了..." | 需要思考的、烧脑的、紧张的 |
| emo/低落 | 被理解、被陪伴、共鸣 | 共情、安静 | "有时候..." | 强行正能量、说教、搞笑 |
| 无聊/兴奋 | 有趣的、搞笑的、能打发 | 轻松、活泼 | "来点有意思的..." | 沉重、严肃、需要专注的 |
| 焦虑/压力大 | 放松的、治愈的、能喘口气 | 平静、舒缓 | "放慢呼吸..." | 制造焦虑的、信息密集的 |
| 想家/孤独 | 有温度的、关于陪伴 | 温暖、怀旧 | "想家的时候..." | 调侃、玩笑、热闹的 |
| 深夜/失眠 | 不费脑、有温度、助眠 | 安静、温柔 | "还没睡的话..." | 刺激的、嘈杂的、需要动脑的 |
| 学习相关 | 知识密度高、实用、有收获 | 清晰、鼓励 | "想看点有信息密度的..." | 娱乐至死、无厘头 |
| 娱乐向 | 好笑、上头、无厘头 | 活泼、挑眉 | "娱乐时间..." | 说教、严肃、需要专注 |

## 时间场景补充

| 时间 | 默认推荐方向 | 调整规则 |
|------|-------------|---------|
| 早上 (6-9点) | 轻松、有活力 | 避免太沉重的 |
| 上午 (9-12点) | 实用、高效 | 适合学习/工作相关 |
| 中午 (12-14点) | 轻松、解压 | 避免太费脑的 |
| 下午 (14-18点) | 适中、有收获 | 可以有点深度 |
| 晚上 (18-22点) | 放松、治愈 | 避免太刺激的 |
| 深夜 (22点后) | 温柔、助眠 | 避免信息密集/烧脑的 |

## 多信号融合

当多个信号同时出现时，**用户明确表达 > 聊天历史 > 时间场景**。

**示例 1**：
- 用户说"好累" + 时间是深夜
- → 优先"累了/疲惫" + "深夜/失眠" → 治愈、温暖、助眠

**示例 2**：
- 用户说"推荐点学习相关的" + 时间是晚上
- → 优先"学习相关" → 知识密度高，但语气可以带一点夜间的温柔

**示例 3**：
- 聊天历史提到"今天好累" + 用户现在说"随便看看"
- → 优先"累了/疲惫" → 治愈方向，而非"无聊/兴奋"

## 内容标签与情绪的对应关系

| 内容特征 | 适合情绪 | 不适合情绪 |
|----------|---------|-----------|
| 萌宠、治愈系、美食 | 累、emo、想家 | 无聊/兴奋（可选） |
| 搞笑、吐槽、反转 | 无聊、压力大 | emo/低落 |
| 深度解读、知识分享 | 学习需求、好奇 | 累、深夜 |
| 旅行、风景、远方 | 想家、孤独、emo | 焦虑（可能加剧） |
| 职场、成长、技能 | 学习、求职、提升 | 深夜、emo |
| 音乐、MV、翻唱 | 任何需要放松的场景 | 极度焦虑（可能分散注意力） |

## 边缘情况处理

| 情况 | 处理方式 |
|------|---------|
| 用户没有明确表达情绪 | 结合聊天历史 + 当前时间推断 |
| 候选池里没有完美匹配的 | 选最接近的，推荐语里做适当铺垫 |
| 用户情绪和内容方向相反 | 以用户明确表达为准，但语气要柔化 |
| 用户说"随便" | 默认选择"轻松、有温度"的方向 |
